# Poprawka kategorii Przemalowanie

- `Przemalowanie` oznacza poprawki wadliwych sztuk i nie wymaga czasu czyszczenia kabiny.
- Dla `Przemalowanie` wymagane jest podanie liczby w polu `Sztuki wadliwe (poprawki)`.
- Czas czyszczenia kabiny pozostaje wymagany dla `Zmiana koloru` oraz `Czyszczenie/Konserwacja`.
- Sam wpisany czas czyszczenia nadal wymaga liczby przezbrojeń.

Podmień `panel.html` i wykonaj `Ctrl+F5`. Migracji SQL nie uruchamiaj.
