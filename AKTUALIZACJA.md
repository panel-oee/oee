# Aktualizacja paczki

Poprawiono sekcję **Ostatnie zakłócenia**. Raporty zmianowe są łączone wyłącznie dla wyniku dobowego, natomiast zakłócenia i notatki są analizowane osobno dla każdej zmiany. Dzięki temu kategorie, czasy i liczba wystąpień nie są zniekształcane.

Migracji SQL nie uruchamiaj ponownie. Podmień pliki HTML i wykonaj `Ctrl+F5`.
